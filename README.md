# بنية الموقع

الموقع ثابت ويبدأ من `index.html` في الجذر. لا يحتاج إلى حزم أو خطوة build.

```text
index.html
README.md
assets/
├── css/       تنسيقات الموقع
├── js/        JavaScript الخاص بتفاعلات الموقع
├── icons/     أيقونات SVG، بما فيها شعارات Tkno الجديدة
└── vendor/    الموارد المنقولة كما هي، مرتبة بحسب مصدرها
```

نُقلت الملفات من `gr/static/` إلى `assets/css/` و`assets/js/` و`assets/icons/`، ونُقلت الموارد التي كانت في `_external/` إلى `assets/vendor/`. حُدّثت مسارات HTML المحلية لتطابق التنظيم الجديد.

## الهوية

- استُبدلت هوية الموقع الظاهرة إلى **Tkno Global** و**Tkno**، وأضيف شعار نصي وأيقونة تبويب محليان بصيغة SVG.
- أُعيدت تسمية النصوص الظاهرة وبيانات العنوان والوصف. بقيت أسماء بعض الخدمات الخارجية مثل Google AI وGoogle DeepMind وGoogle Labs وGoogle Cloud دون تغيير حتى تظل روابطها معرّفة بأسمائها الرسمية.
- بقيت أسماء الخطوط والنطاقات وروابط الخدمات والشيفرات الخارجية والتراخيص كما هي؛ لم يُجرَ استبدال شامل داخل ملفات vendor.

## الخطوط

- تعريفات الخطوط وتقسيمات المحارف باقية في ملفات CSS ضمن `assets/vendor/fonts.googleapis.com/`، وتُحمّل ملفات الخطوط مباشرة من `https://fonts.gstatic.com/`.
- أزيلت **237 نسخة WOFF2 محلية** (نحو **9.05 MB**). يتطلب عرض الخطوط اتصالًا بالإنترنت إلى Google Fonts CDN؛ وإذا تعذّر الوصول إليه فسيظهر خط بديل من النظام.

## المعاينة محليًا

من PowerShell داخل هذا المجلد، إذا كان Python متاحًا:

```powershell
py -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## GitHub Pages

لا يحتوي هذا المجلد حاليًا على إعداد GitHub Actions؛ أبقيت `.github` محذوفًا كما طلبت. للنشر اليدوي، اختَر في إعدادات Pages الفرع الذي يحتوي على الموقع ومجلد الجذر `/` كمصدر للنشر. لا توجد خطوة build مطلوبة.

لا حاجة إلى `.nojekyll` في هذه البنية؛ لم تعد هناك مجلدات موقع تبدأ بشرطة سفلية مثل `_external/`.

## ملاحظات

- المحتوى والصور المنقولة في الموقع مصدرها Google Research؛ تحقّق من حقوق إعادة النشر ومصدر المحتوى قبل نشره للجمهور.
- لم يُحدّد عنوان النشر العام النهائي بعد؛ لذلك أزيلت قيم canonical و`og:url` وصورة المشاركة القديمة بدل الإشارة إلى عنوان Google. أضف قيمًا مطلقة صحيحة وصورة مشاركة خاصة بـTkno بعد تثبيت النطاق.
- يتضمن الموقع موارد وروابط خارجية، ومنها تحميل الخطوط من `fonts.gstatic.com`.
